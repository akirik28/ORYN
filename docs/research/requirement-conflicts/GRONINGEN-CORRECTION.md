# Correction: Groningen was never the "older page is correct" counterexample

**Raised 2026-08-22 by the conflict-resolution pass. Three documents still assert the old
version; this file is the correction they should be read against.**

## What was believed

A standing rule in this project says: *"trust the more recently updated page" is not a safe
heuristic* — and it has been cited, repeatedly and in good faith, with Groningen as its
counterexample. The claim was that Groningen's older-looking page is the correct one while
Erasmus's newer content is correct, so a recency rule gets one right and one wrong.

That framing appears in at least:

- `docs/ORYN_WORKSTREAMS.md`, the DE-NL-REQUIREMENTS row
- `docs/research/university-requirements/de-nl-requirements-deadlines-summary.md:174`
- `docs/handoffs/requirements-ingestion-design.md:351`

It also travelled through coordination briefs into several lanes' working assumptions, including
the counselor-knowledge lane's first Netherlands draft.

## What is actually true

**The two Groningen pages do not disagree. They agree exactly, to the day.**

The hub page's FEB entry is a **2×2 table** — prior education × start month:

| | September start | February start |
|---|---|---|
| **RUG bachelor's** | 1 August | 1 January |
| **Other prior education** | **1 May** | **15 October** |

The original record flattened that table into a flat list and paired **1 August** against
**1 January** as the two competing answers. Those are two cells of the *same row*, describing
two different start months.

The FEB international-diploma page states 1 May for September start and 15 October for February
start — precisely the "other prior education" row, which is the row an international-diploma
applicant falls in.

The apparent 16-month gap that made this look like a conflict came from comparing a
February-start date against a September-start date across rows.

## Where the counterexample actually lives

**Heidelberg.** A recency heuristic there would prefer the modern, undated faculty page, while
such substantive evidence as exists leans toward the older documents. It remains genuinely
unresolved — see `11-heidelberg-uniassist-medicine.md`.

Heidelberg is a much better counterexample than Groningen ever was, because the difficulty is
real rather than an artifact: there is no current dated source at all, and the only
counter-evidence is an undated page's *silence*.

## The rule that survives, and the one that replaces it

**The standing rule is unchanged and still correct**: do not resolve a source conflict by
preferring the more recently updated page. Cite Heidelberg for it, not Groningen.

**A second rule is added, and it would have prevented this entirely:**

> A table flattened into a list is how a non-conflict becomes a recorded conflict. When two
> "competing" values differ by an implausible interval, suspect the comparison before suspecting
> the sources.

Sixteen months between two deadlines for the same programme was never plausible. That
implausibility was visible at record time and read as evidence of how bad the conflict was,
rather than as evidence that the comparison was malformed.

## Why this is worth its own document

The conflict pass found that **nine of twelve resolved conflicts were never conflicts** — two
true statements about different things, recorded as competing answers to one question. Groningen
is the clearest instance, and it is the one that got promoted into a standing rule and cited
onward.

A wrong fact costs one record. **A wrong rule costs every record it is applied to afterwards.**
